The purpose of this project is to assist users who are new to using git for version control in their projects. It will give them advice on which commands to run along with a short explaination on why based on the current state of the repository.

It will not run commands for them, only offer suggestions.

The scope is limited to basic git usage that an analyst using git needs to know, not advanced usage tips that a software engineer might need.

Python version: 3.14
Version control: uv
Build specifications:
    - cli functionality with typer
    - color coded terminal messages with rich
    - Strict typing with mypy
    - Build and run test suite using pytest
